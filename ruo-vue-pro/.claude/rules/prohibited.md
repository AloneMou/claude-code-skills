# 禁止事项清单

> 严格禁止的做法，违反这些规则将导致代码审查不通过。

## 数据处理

1. **禁止** 手动设置 `createTime`/`updateTime`/`creator`/`updater`/`deleted` — BaseDO 自动填充
2. **禁止** 绕过 `CommonResult` 直接返回裸数据
3. **禁止** 在 Controller 写业务逻辑 — 全部委托给 Service
4. **禁止** 直接用 MyBatis-Plus 原生 `QueryWrapper`/`LambdaQueryWrapper` — 用 `LambdaQueryWrapperX`
5. **禁止** 在 XML 写简单查询 — 用 Mapper 的 `default` 方法
6. **禁止** 硬编码错误信息 — 必须用 `ErrorCodeConstants`
7. **禁止** 忽略 `@PreAuthorize` 权限注解 — 每个接口必须有
8. **禁止** 使用 `javax.*` 包 — Spring Boot 3 用 `jakarta.*`

## 架构层面

9. **禁止** 模块间直接跨层调用 — 模块 A 调模块 B 必须通过 B 的 `api/` 接口
10. **禁止** 循环依赖 — 模块 A 调 B，B 不得调 A
11. **禁止** 在 Service 中直接注入其他模块的 Mapper — 必须通过 API
12. **禁止** 绕过 Service 接口直接引用 Impl 类
13. **禁止** 在 DO 中引用其他模块的类 — DO 必须自包含

## 安全

14. **禁止** 在日志中输出用户敏感信息（密码、token、手机号等）
15. **禁止** 拼接 SQL — 必须用参数化的条件构造器
16. **禁止** 在 URL 中传递敏感参数 — 用请求体传输
17. **禁止** 关闭 CSRF/安全过滤器而不加注释说明原因

## 性能

18. **禁止** N+1 查询 — 用批量查询或 JOIN 代替
19. **禁止** 在循环中执行数据库操作 — 用批量操作
20. **禁止** 全表扫描 — 确保查询条件有索引
21. **禁止** 不分页查询大数据集 — 超过 1000 条必须分页
22. **禁止** 在不需要的地方查询关联数据 — 按需加载

## 代码质量

23. **禁止** 捕获异常后不处理 — 至少记录日志或重新抛出
24. **禁止** 使用魔法数字 — 用常量或枚举代替
25. **禁止** 方法超过 50 行 — 拆分职责
26. **禁止** 在提交代码中包含 `TODO`/`FIXME` 而不创建对应的 Issue
27. **禁止** 使用 `System.out.println` — 用日志框架
